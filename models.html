What Findings is, and what is training inside it.

Findings is a computer vision project for medical imaging. Each model takes an image, detects one radiographic finding, and turns that finding into a sentence of report text — the same sentence a radiologist would have to write anyway. The project is the thing being built; the models are how it gets built, and there is more than one.

Damoiseau

Modality Chest radiograph Finding Pleural effusion Status v1 trained, calibrated

The first model, and the one this devblog has documented from the starting line. It scores a frontal chest radiograph for pleural effusion and hands that score to a report generator. v1 reached an AUROC of 0.879 on held-out test data using 22% of the dataset on a free GPU — a number that looked fine and hid a calibration failure underneath it, which is the subject of the entries below.

The name is for Louis-Hippolyte-Joseph Damoiseau, whose curve describes the upper border of a pleural effusion on a chest film.

The second model

Modality MRI Finding Not yet published Status In training

A second model is being trained in parallel, on magnetic resonance imaging rather than radiographs. It is a different modality, a different finding, and a different set of problems — MRI arrives as a volume with multiple sequences, not as one projection, and almost nothing learned from the chest X-ray pipeline transfers to it unchanged.

It has a working name internally and it is deliberately not printed here. Naming a model in public is a small promise that the thing exists in the shape the name implies, and this one has not yet produced a result worth standing behind. It gets an entry, and a name, when it does.

Not a medical device. Findings is a research and portfolio project. No model here is cleared by ANVISA, the FDA, or any regulator, and nothing any of them produces should be used to make a decision about a patient. Every output carries a mandatory human-review flag by design — a radiologist reads it, and the radiologist signs it. All data comes from public research datasets. No patient data from clinical practice enters this project.
